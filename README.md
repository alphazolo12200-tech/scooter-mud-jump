# 🛴 Scooter Mud Jump

A first-person scooter stunt game that runs in any browser. Pedal up to speed, hit the ramp, fly over the balloons and splash into the mud!

**▶ Play it:** https://alphazolo12200-tech.github.io/scooter-mud-jump/

## Features
- 4 scooters: Kick Scooter, Stunt Scooter, E-Scooter and Retro Moped
- 5 worlds: Meadow, Desert, Snow, Night and Volcano
- 5 levels, 3 ramp angles and an Adrenaline Dare mode
- Flips, plus No-Hands, Superman and Tailwhip tricks with combos
- Boost, coins, an upgrade shop and unlockable scooters
- Music and sound effects, with a mute button
- Phone-friendly on-screen controls (best in landscape)

## Controls
| Action | Keyboard | Phone |
|---|---|---|
| Push / flip in the air | Space | PUSH button or tap |
| Boost | B | BOOST button |
| Trick (in the air) | T or ↑ | TRICK button |
| Mute | M | 🔊 button on the menu |

**Tip:** Land flat and wait until the trick animation ends, or you crash!

## Built with
HTML5 Canvas, vanilla JavaScript and the Web Audio API in a single `index.html`. No libraries, no build step. Progress is saved in your browser's localStorage.
